🚀 Clone & Reproduce Benchmarks on Your Machine: 

# 1. Clone repo & set key
git clone https://github.com/username/subdollar-LLM-coding-bench.git && cd subdollar-LLM-coding-bench
export OPENROUTER_API_KEY="sk-or-v1-..."

# 2. Run Redis or HTTP benchmark
cargo run --release -- run --task redis --model openrouter/meta/muse-spark-1.3-contributor --effort max

# 3. Publish results to git & regenerate SUMMARY.md
cargo run --release -- publish --run-id <run_id>
